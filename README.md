# Cozy RPG Pack

Minecraft 1.20.1 with Forge 47.4.23. Your mods update themselves every time you launch the game.

## What you need

- [Prism Launcher](https://prismlauncher.org/)
- A Microsoft account with Minecraft Java Edition
- About 8 GB of free RAM for the game

## Setup (one time)

1. Download the `Cozy RPG Pack.zip` file from Dylan.
2. Open Prism Launcher and click **Add Instance**.
3. Choose **Import** on the left, pick the zip, and click **OK**.
4. Right-click the new instance, open **Edit**, go to **Settings > Java**, and check that the maximum memory is set between 6144 and 8192 MB.
5. Double-click the instance to launch it. The first launch downloads about 80 mods, so it takes a minute or two. A small updater window appears while this happens.

## Joining the server

In the main menu, click **Multiplayer > Add Server** and enter the address Dylan gives you.

## Troubleshooting

- **The updater window shows an error:** check your internet connection and relaunch. If it keeps failing, send Dylan a screenshot.
- **The game crashes on launch:** make sure the instance has at least 6 GB of RAM (step 4).
- **"Mod mismatch" when joining:** close the game and launch again so the updater can fetch the latest mods.
