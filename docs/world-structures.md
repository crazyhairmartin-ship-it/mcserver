# World structures

Generated by `tools/quests/make_structures.py` from the pack's jars and overrides. 676 structures in total; **634 generate** in new chunks. Rarity is from the structure set's spacing in chunks (very common <=12, common <=24, uncommon <=40, rare <=80, very rare above; a frequency below 1 thins the grid, counted as spacing / sqrt(frequency)). "Rings" are placed in rings around spawn (strongholds); "fixed grid" is the Twilight Forest's own layout, where each landmark has its set place in the grid.

Quest start points and how to use each kind of structure: see the "Structures as quest start points" section of `docs/superpowers/specs/2026-10-13-boss-progression.md`.
